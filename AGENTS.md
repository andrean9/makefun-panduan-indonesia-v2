Technical guide and content standards for this repository.

## What this is

An Indonesian-language getting-started guide for make.fun, written for the
bring-the-humans-02 bounty. The guide teaches a new user, in Bahasa Indonesia,
how to create a make.fun account, connect a wallet, join a bounty, and submit
an entry — with the author's referral code.

- Bahasa Indonesia throughout; keep the tone clear and beginner-friendly.
- Keep the three live make.fun badges at the top of the README (the
  competition badge, the rank badge, and the reward badge, with this
  repository's owner and name in their URLs). A static badge does not count.
- Keep the referral code `66rnv3bx` in the guide.
- Keep the screenshot current: it must show the published GitHub page of
  this repository.
- Do not add code, scripts, or build tooling — this repository is a guide,
  not an app.
